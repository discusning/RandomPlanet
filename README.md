# 랜덤 플래닛 (Random Planet)

> 캐릭터 자체가 가챠다 — 매번 랜덤으로 굴려진 캐릭터로 도전하는 로그라이트 액션

메이플스토리 월드 글로벌 개발 콘테스트 제출작 · **리롤 스튜디오 (Re:Roll Studio)** · 유한대학교

---

## 개요

| | |
|---|---|
| **플랫폼** | 메이플스토리 월드 (mLua + Unity 기반) / PC·모바일 크로스플랫폼 |
| **장르** | 로그라이트 액션 / 핵 앤 슬래시 |
| **플레이 모드** | 싱글 플레이(솔로) 전용 |
| **사용 리소스** | 메이플스토리 5차 전직 이전 에셋 |

캐릭터의 스탯·특성·스킬이 전부 랜덤으로 결정되는 로그라이트. 옛날 메이플 직업 스킬(전사/마법사/궁수/도적/해적, 1차 10종)을 뽑아 전투를 진행한다. 최종 목표(특성 100종·패시브 100종·링크스킬 100종의 완전한 가챠 레이어)는 `Docs/`의 원본 기획서에 있고, **지금 실제로 MSW에 구현·플레이 가능한 범위는 그보다 작은 MVP 단계**다 — 정확한 현재 상태는 아래 "지금 어디까지 만들어졌는지" 항목 참고.

## ⚠️ 이 저장소로 처음 작업 시작하기 전에

1. **`Archive/As-built.md`를 먼저 읽는다.** 실제로 뭐가 구현됐고 뭐가 아직 안 됐는지, 세션마다 갱신되는 현재 상태 스냅샷이다. 기획서(`Docs/`)는 "최종 목표"고, As-built.md가 "지금 실제 모습"이다.
2. **로컬 폴더는 컴퓨터당 하나만 유지한다.** 같은 저장소를 여러 폴더에 따로 클론해두면 어느 쪽이 Maker에 연결된 진짜 작업 폴더인지 헷갈려서 "분명 커밋했는데 게임엔 안 보인다" 문제가 생긴다. GitHub Desktop에서 새로 저장소를 열 때 항상 기존에 쓰던 그 폴더를 열 것 — "Clone"이 아니라 "Add local repository"(또는 기존 항목 그대로 사용).
3. **MSW Maker의 Local Workspace를 이 폴더로 연결한다.** 그룹 월드 진입 시 폴더 선택 창이 뜨면 이 클론 폴더를 지정한다.
4. **`.mcp.json`은 직접 만든다.** `.mcp.json.example`을 복사해서 `.mcp.json`으로 이름을 바꾸고, 본인 Windows 사용자명과 본인 MSW MCP 토큰을 채워 넣는다 (이 파일은 토큰이 들어있어서 git에 올라가지 않는다).

## ⚠️ git과 MSW World는 동기화 방식이 다르다 — 협업 시 반드시 지킬 것

**git은 여러 명의 변경사항을 파일 단위로 병합할 수 있지만, MSW 클라우드 월드 상태는 병합이 안 된다 — 마지막으로 저장/동기화한 사람 것으로 그냥 덮어써진다.** 그래서 두 명이 동시에 Maker를 켜놓고 각자 작업하면 한쪽 작업이 조용히 사라질 수 있다.

작업할 때는 이 순서를 지킨다:

1. `git pull` (최신 변경사항 받기)
2. Maker에서 **Refresh** (워크스페이스 재적재)
3. 작업
4. Maker에서 **저장** (`File > Save` 또는 Sync to Remote Workspace — 그룹 리더/매니저만 가능)
5. `git add` → `commit` → `push`
6. 팀 채널에 "작업 끝났다"고 알리기 — 다음 사람은 그 뒤에 시작

**동시에 두 명이 Maker를 켜놓고 편집하지 않는다.** 한 명씩 순서대로.

## 폴더 구조

| 경로 | 내용 | 편집 주체 |
|---|---|---|
| `RootDesk/MyDesk/` | 실제 게임 스크립트(`.mlua`)·모델(`.model`) | 개발(AI/팀원) |
| `map/` | 맵 파일(`.map`) — Maker가 실제로 읽는 위치 | 개발 |
| `ui/` | UI 파일(`.ui`) | 개발 |
| `Global/` | MSW 엔진 기본 템플릿(읽기 전용, Maker 에디터에서만 수정) | Maker 직접 편집 |
| `Archive/As-built.md` | **현재 실제 구현 상태 스냅샷 — 매 세션 갱신, 새 세션은 이거부터 읽는다** | 매 세션 |
| `Docs/` | 원본 기획서·인게임 로드맵·Phase별 상세 문서 | 기획 |
| `History/` | 2026-08-02~09 사이의 옛 진행 기록(현재는 `Archive/As-built.md`가 이 역할을 대신함, 과거 기록 보존용) | (동결됨) |
| `.claude/` | Claude Code 스킬/설정 (MSW 작업 규칙이 여기 들어있음, `AGENTS.md` 참고) | 건드리지 않음 |

## 지금 어디까지 만들어졌는지

전체 로드맵·현재 마일스톤·직전 세션에서 뭘 했는지는 항상 [`Archive/As-built.md`](./Archive/As-built.md)의 "📍 Quick Status"를 확인한다. 요약하면:

- Phase 0(캐릭터 선택)·스탯 시스템·장비 시스템·스킬 시스템(전직마다 버프/공격 각 1택)·UI 4분할까지 구현·검증 완료
- Phase 1(전투 맵) 준비는 여전히 유일한 실사용 블로커 — Maker에서 직접 처리해야 하는 작업
