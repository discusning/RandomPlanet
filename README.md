### 핵심 루프

```
[로비] 캐릭터 생성(하루 최대 6개, 스탯·특성 전부 랜덤) → 공격대 편성(플레이어블 1 + 링크 2)
   → [전장] 입장 → 몬스터 웨이브 처치 → 레벨업 → 5·13·18레벨에 2~4차 전직
   → 3레벨 단위로 이능 선택(스탯 재분배 / 추가 스탯 / 특성 변경 중 1개) → 중간 보스 → 클리어 또는 사망
   → [로비] 클리어 보상으로 영구 재화 획득 → 계정 강화 → 다시 처음으로
```

캐릭터 사망은 영구 삭제(로그라이트 확정)지만, 계정 영구 재화는 남아서 다음 캐릭터를 강화하는 데 누적된다.

### 캐릭터 시스템

- **스탯**: 힘/민첩/지능/행운 4종, 생성 시 전부 랜덤 분배 (힘=물리공격력, 민첩=공격속도·명중, 지능=스킬데미지·최대MP, 행운=크리티컬)
- **특성(Trait)**: 5개 확률 풀(Hidden-good/Hidden-bad/average/bad/Gamble)에서 랜덤 1개, 3차 전직 시 1개 추가. 특성 하나마다 **기본 패시브**(직접 플레이 시 상시 발동)와 **링크 패시브**(그 캐릭터를 링크로 편성했을 때 팀 전체에 적용, 15레벨 이상부터) 2개가 고정으로 함께 딸려온다
- **스킬**: 매 전직(1·5·13·18레벨)마다 메이플 옛날 직업 스킬 중 **버프 3택1 + 공격 3택1**을 동시에 획득 (전 직업 통합 풀이라 하이브리드 빌드 가능, 4차까지 최대 8개)
- **공격대**: 플레이어블 1 + 링크 2 = 총 3명. 링크 캐릭터는 15레벨 이상이면 본인 특성의 링크 패시브를 팀에 제공

> 최종 기획(특성 100종+·패시브/링크 100종씩의 완전한 가챠 레이어, 부록 포함 전체 상세)은 [`Docs/랜덤 플래닛 전체 기획서.md`](./Docs/랜덤%20플래닛%20전체%20기획서.md)에 있다. **지금 MSW에 실제로 구현·플레이 가능한 범위는 이 중 축소된 MVP 일부**다 — 정확한 현재 상태는 아래 "지금 어디까지 만들어졌는지" 참고.

## ⚠️ 이 저장소로 처음 작업 시작하기 전에

1. **`Archive/As-built.md`를 먼저 읽는다.** 실제로 뭐가 구현됐고 뭐가 아직 안 됐는지, 세션마다 갱신되는 현재 상태 스냅샷이다. 기획서(`Docs/`)는 "최종 목표"고, As-built.md가 "지금 실제 모습"이다.
2. **로컬 폴더는 컴퓨터당 하나만 유지한다.** 같은 저장소를 여러 폴더에 따로 클론해두면 어느 쪽이 Maker에 연결된 진짜 작업 폴더인지 헷갈려서 "분명 커밋했는데 게임엔 안 보인다" 문제가 생긴다. GitHub Desktop에서 새로 저장소를 열 때 항상 기존에 쓰던 그 폴더를 열 것 — "Clone"이 아니라 "Add local repository"(또는 기존 항목 그대로 사용).
3. **MSW Maker의 Local Workspace를 이 폴더로 연결한다.** 그룹 월드 진입 시 폴더 선택 창이 뜨면 이 클론 폴더를 지정한다.
4. **`.mcp.json`은 직접 만든다.** `.mcp.json.example`을 복사해서 `.mcp.json`으로 이름을 바꾸고, 본인 Windows 사용자명과 본인 MSW MCP 토큰을 채워 넣는다 (이 파일은 토큰이 들어있어서 git에 올라가지 않는다).

## ⚠️ git과 MSW World는 동기화 방식이 다르다 — 협업 시 반드시 지킬 것

**git은 여러 명의 변경사항을 파일 단위로 병합할 수 있지만, MSW 클라우드 월드 상태는 병합이 안 된다 — 마지막으로 저장/동기화한 사람 것으로 그냥 덮어써진다.** 그래서 두 명이 동시에 Maker를 켜놓고 각자 작업하면 한쪽 작업이 조용히 사라질 수 있다.

작업할 때는 이 순서를 지킨다:

1. `git pull` (최신 변경사항 받기)
2. Maker에서 **Refresh** (워크스페이스 재적재)
3. 작업
4. Maker에서 **저장** (`File > Save` 또는 Sync to Remote Workspace — 그룹 리더/매니저만 가능)
5. `git add` → `commit` → `push`
6. 팀 채널에 "작업 끝났다"고 알리기 — 다음 사람은 그 뒤에 시작

**동시에 두 명이 Maker를 켜놓고 편집하지 않는다.** 한 명씩 순서대로.

### 맵 작업 담당자를 위한 안내

MSW Maker는 **`./map/` 폴더에 있는 `.map` 파일만** 인식한다 — 다른 위치(예: 저장소 루트에 별도 폴더)에 만든 맵은 Maker에 아예 안 보인다. 그래서 별도의 "맵 전용 폴더"를 새로 만드는 대신, 다음 규칙만 지키면 된다:

- **작업 중인 맵도 그냥 `map/`에 둔다.** `SectorConfig.config`의 `entries`에 등록하기 전까지는 실제 게임 플레이에 아무 영향이 없다 — Maker Hierarchy에서 열어보고 편집하는 용도로는 완전히 안전하다.
- **기존 맵과 이름이 겹치면(`Lobby.map`, `choice_map.map` 등) `_teammate` 같은 접미사를 붙여 구분한다.** 실제로 반영할 때 담당자가 확인 후 원래 이름으로 병합/교체한다.
- 2026-08-11에 팀원이 저장소 루트 `testmap/`에 올렸던 맵 7개(`토벌전장1~3.map` 포함)는 Maker가 인식 못 하는 위치에 있어서 그대로는 죽은 파일이었다 — 이번에 `map/`으로 옮겼다. **`토벌전장1~3.map`은 Phase 1 Task 1(전투 맵 블로커)에 쓸 수 있는 후보로 보이니, Maker에서 열어 TileMapMode·Foothold 상태를 확인해볼 것.**
