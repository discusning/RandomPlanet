- **[해결] 설정창 "키 설정" 버튼 텍스트가 "ㅋㅋ 설정"으로 깨져 있던 오타/데이터 오염 버그.**
- **[해결] 다른 캐릭터로 전환해도 전투력(전투력 배지)이 모든 캐릭터에 동일하게 표시되던 버그.** 원인: `PlayerAttack.mlua`의 공격력/치명타/공속 등 속성이 `@Sync` 누락 상태라 서버가 캐릭터별로 재계산한 값이 클라이언트(UI가 읽는 쪽)로 전달되지 않고 있었음 — 항상 스크립트에 선언된 기본값만 보이던 것. `@Sync` 추가로 해결, 서로 다른 스탯의 캐릭터 2명으로 직접 재현·검증(전투력 값이 실제로 달라짐을 확인).
- **[해결] 일부 스킬 사용 직후 기본 공격이 이어서 나가는 현상.** 원인: 스킬 사용(`UseSkill`)과 기본 공격(`DoAttack`)이 서로 무관한 쿨다운 타이머로 각각 동작하고 있어서, 기본 공격 키를 누르고 있는 상태에서 스킬을 쓰면 타이밍이 우연히 겹쳐 기본 공격이 스킬 직후에 새어나가는 경우가 있었음(특정 스킬의 결함이 아니라 타이밍 우연). 스킬 사용 시 기본 공격 쿨다운도 함께 갱신하도록 수정(메이플스토리처럼 스킬 사용이 기본 공격 딜레이도 리셋).
- **[정보→해결 정정] "I" 단축키(인벤토리)가 가끔 안 먹히는 것처럼 보이는 현상 — 최초엔 "코드 문제 아님(입력 시뮬레이터 노이즈로 추정)"으로 결론 냈었으나, 같은 날 전체 코드 감사 중 실제 코드 버그로 재확인·수정됨 (아래 "게임 전체 분석" 항목 참고).**

### ✨ 기능 추가

- **[완료] 인벤토리 UI를 장비/소비/기타 3개 탭으로 분리.** 기존엔 장비 아이템과 주문서(소비)가 한 그리드에 섞여 있던 것을, 실제 메이플스토리처럼 카테고리별 탭으로 나눠서 보이도록 개편. 내부 데이터 구조(캐릭터의 flat 인벤토리 배열)는 그대로 두고 화면 표시 로직만 카테고리 필터링하도록 변경 — 장착/주문서 사용 로직은 변경 없이 그대로 동작. "기타" 탭은 현재 해당하는 아이템이 없어 항상 비어있지만, 추후 재료·퀘스트 아이템 등이 추가되면 자동으로 채워지는 구조로 미리 준비해둠.

### 🔍 게임 전체 분석 (유저 요청: "게임 전체적으로 분석해서 시스템 상 오류 있다면 해결해")

`RootDesk/MyDesk/` 아래 모든 `.mlua` 스크립트(24개) 전수 검토 + 의심 지점마다 `maker_execute_script`로 직접 재현·검증. 3건의 실제 버그를 새로 찾아 수정:

- **[해결] "I" 단축키로 인벤토리 창이 가끔 안 열리던 진짜 원인 발견 — 핸들러 중복 등록으로 인한 이중 토글.** `LobbyStageController`가 "I" 키를 하드코딩으로 직접 처리하고 있었는데, 전역 로직인 `WindowHotkeyLogic`도 (리바인딩 가능한 키 설정을 통해) 똑같은 "I" 키를 인벤토리 토글로 처리하고 있어서 — 한 번 누르면 두 핸들러가 동시에 반응해 열림→닫힘(또는 닫힘→열림→닫힘)으로 사실상 "아무 일도 안 일어난 것처럼" 보였던 것. 이전 세션에서 "입력 시뮬레이터 노이즈"로 오진단했던 게 바로 이 버그였음. 하드코딩된 중복 핸들러 제거, `WindowHotkeyLogic` 하나만 남김(리바인딩도 이제 정상 반영됨). 키보드 입력 시뮬레이션으로 직접 재검증(한 번 누르면 정확히 한 번 토글).
- **[해결] 관통형 스킬(애로우 블로우 등)이 한 몬스터에게 의도보다 많은 피해를 입히던 버그.** 관통 투사체가 같은 몬스터를 여러 프레임에 걸쳐 중복으로 맞히고 있었음(한 번만 맞혀야 하는데). 직접 재현: 고정된 표적 하나에 한 번 스킬을 썼는데 2번 타격분(17이 아닌 34) 피해가 들어감. 수정 후 정확히 1회 타격만 들어가는 것 확인.
- **[해결] 화면 하단 스킬 쿨다운 카운트다운 표시가 미세하게 부정확했던 문제.** 서버가 찍은 스킬 사용 시각과 클라이언트가 표시에 쓰는 시각이 서로 다른(동기화 안 된) 시계값이었음 — 실측으로 확인(클라이언트/서버 시각이 약 0.5~1.4초 정도 어긋남). 서버와 동기화된 시각값으로 교체해 수정.

수사 과정에서 "버그처럼 보였지만 실제로는 정상"으로 확인되어 넘어간 것들도 기록: 투사체 공격력 관련 속성 미동기화(화면에 표시 안 되므로 문제 없음), 커스텀 스크립트의 네이티브 컴포넌트 접근 방식(정상 동작 확인), 원거리 스킬이 처음엔 데미지 0으로 보였던 것(실은 몬스터를 물리엔진이 있는 상태에서 잘못된 방법으로 옮겨서 위치가 실제로는 안 바뀌었던 테스트 실수 — 실제 게임 버그 아님).
