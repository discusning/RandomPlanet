# 랜덤 플래닛 — 보완 히스토리

> 이 파일은 게임을 만들면서 나온 **"보완할 점"을 날짜별로 기록**하고 해결 여부를 추적하기 위한 문서입니다. 개발용 PC로 돌아가서 바로 이어서 작업할 수 있도록, 각 항목마다 상태(**해결**/**미해결**)와 상세 내용이 있는 위치를 남겨둡니다.
>
> **전반적인 진행률(%)**은 이 파일이 아니라 `History/RandomPlanet-Status-2026-08-02.md`를 참고하세요 — 이 파일은 "무엇을 고쳐야 하는지/고쳤는지"에만 집중합니다.

## 사용법

- 새 문제/개선점이 나오면 그날 날짜 아래에 `[미해결]`로 추가
- 해결되면 `[해결]`로 바꾸고 해결 날짜·방법을 한 줄 덧붙임 (기존 텍스트는 지우지 말고 남길 것 — 이 프로젝트는 git 히스토리가 없어서 이 파일 자체가 유일한 기록임)
- 미해결 항목이 많아지면 파일 맨 위에 "현재 미해결 요약" 섹션을 추가할 것 (지금은 항목이 적어 생략)
- **날짜는 유저가 매번 알려주지 않아도 AI가 그 시점의 실제 날짜로 알아서 기입한다** (2026-08-02부터 적용된 규칙)

## 2026-08-02

### 🎮 인게임 (실제 MSW 프로젝트 — `랜덤 플래닛 인게임.md` 참고)

- **[미해결] Phase 1 Task 1 — 전투용 MapleTile 맵 준비 안 됨.** AI가 대신 할 수 없는 유일한 블로커. Maker에서 새 맵 생성 → Hierarchy 우클릭 → Switch TileMap → MapleTile(TileMapMode=0) 전환 → Foothold 배치. 완료 즉시 `TestSlime.model`을 그 맵에 재배치하면 Phase 1 전체 완료.
- **[미해결] UI가 전반적으로 허접함(데모 버전 기준).** 카드 패널·버튼 대부분이 손으로 색 입힌 기본 도형/색상 스프라이트 수준이라 유저가 불만족.
  - **원인 진단**: AI(이 세션)의 그림/영상 생성 능력이 다른 AI 대비 부족할 수 있다는 게 유저의 가설. 다만 유저 본인도 "디자인 계열이 아니다"라고 밝힘 — AI가 새로 그리는 것보다 **완성된 외부 에셋을 가져다 쓰는 쪽이 안전한 방향**이라고 유저가 직접 결정.
  - **확정된 진행 방식**: 유니티 애셋스토어 패키지 등 랜덤 플래닛 컨셉(메이플풍 파치먼트/브라운/골드)에 맞는 기존 UI 에셋 패키지를 찾아서, 그 안의 PNG 파일들을 하나씩 꺼내 프로젝트의 각 UI 요소(카드 패널/버튼/삭제 확인 팝업/등급 테두리 등)에 매칭·업로드하는 방식으로 진행하기로 함. (MSW는 유니티 에디터가 아니라 `.unitypackage` 통째 임포트는 불가하지만, 개별 PNG는 `asset_create_resource_storage_item` 업로드 API로 등록 가능 — 확인 완료)
  - **후보 조사 완료**: 1순위 [Medieval Fantasy RPG UI Kit - Gothic & Gold](https://vill8tion.itch.io/medieval-fantasy-rpg-ui-kit-gothic-gold-4k)(무료, 파치먼트/우드/골드 재질이 현재 배색과 일치), 2순위 [Emberforge RPG UI Kit Pro](https://www.artstation.com/marketplace/p/lrdJl/emberforge-rpg-ui-kit-pro-fantasy-inventory-shop-crafting-ui-assets)(유료, 아이템 등급별 프레임이 특성 등급 체계와 잘 맞음).
  - **다음 단계(미착수)**: 유저가 후보 중 하나를 다운로드해서 파일 경로를 주면 → 압축 해제 → PNG 추출·매칭 → 실제 MSW 업로드까지 진행 예정.
  - **다운로드 위치**: 유저가 `RandomPlanet` 폴더 안에 넣어둘 예정 — AI가 하위 폴더(예: `Assets-외부/`) 하나 새로 만들어서 그 안에 정리하는 걸 제안함(`RootDesk`/`Global`/`Environment` 등 MSW 자체 구조와 안 섞이게). 최종 폴더명은 유저가 실제로 파일을 넣을 때 확정.
- **[미해결] 로비 스폰 좌표가 의도한 발판이 아닌 더 낮은 곳(`y≈-6.62`)에 착지.** 추락사는 아니라 게임 진행엔 지장 없음. Lobby의 foothold 레이어(`groupID`) 구조 재조사 필요.
