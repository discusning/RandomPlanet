게임 개요

옛날 직업 스킬·전직·이능·마노·달팽이 같은 메이플 IP 친화 요소를 그대로 살리면서, 랜덤 시스템을 게임의 중심 메커니즘으로 끌어올린 로그라이트.

가제랜덤 플래닛 (RANDOM PLANET)
장르로그라이트 액션 / 핵 앤 슬래시
한 줄 소개캐릭터 자체가 가챠다 — 매번 랜덤으로 굴려진 캐릭터로 도전하는 로그라이트
핵심 재미스탯·특성·스킬이 전부 랜덤 → 같은 판이 없음. 강캐를 뽑고 빌드를 완성해가는 재미

콘테스트 어필 포인트 — 메이플 IP 친화 요소(옛날 직업 스킬·전직·이능·마노·달팽이)를 그대로 살리면서, 랜덤 시스템을 게임의 중심 메커니즘으로 끌어올린 로그라이트. 메이플스토리 5차 이전 에셋·보스를 적극 활용해 IP 친숙도를 극대화한다.
01

핵심 게임 루프

1-1메타 루프 (로비)

  • 캐릭터 생성 — 하루 최대 6개, 스탯·특성 전부 랜덤
  • 보관 — 캐릭터 선택창(최대 6칸)에서 관리
  • 공격대 편성 — 플레이어블 1 + 링크 2
  • 입장 — 토벌 전장 / 몬스터 게이트 선택
  • 정산 — 클리어 보상으로 영구 재화 획득 → 계정 강화 → 1번으로 회귀
캐릭터가 전부 소진되고 당일 생성권도 없으면 다음 날 생성권 회복까지 대기.

1-2인게임 루프 (전장)

스폰 → 좌우 포털에서 몬스터 웨이브 등장 → 처치 시 스탯 구슬 / 경험치 드랍 → 레벨업 → [5·13·18레벨] 2·3·4차 전직 + 전직 퀘스트 보스 클리어 → [3레벨 단위] 이능 선택 → 중간 보스 난입 (막대한 경험치) → 사냥터 클리어 또는 캐릭터 사망 → ENDING
02

캐릭터 시스템

2-1캐릭터 생성 및 공격대

  • 캐릭터 선택창 최대 6칸 — 모든 슬롯이 플레이어블 속성을 가짐
  • 그 중 1개를 선택해 직접 조작 (플레이어블 캐릭터)
  • 나머지 중 최대 2개를 링크로 지정 → 공격대 총 3명 구성
  • 링크 캐릭터는 15레벨 이상일 때 배정된 링크스킬을 공격대에 제공 (2-8 참조)
  • 공격대에 플레이어블 1개만 있어도 도전 가능
  • 캐릭터 생성은 하루 최대 6개 (매일 초기화)
  • 캐릭터 사망 → 해당 캐릭터 1개만 영구 삭제 (링크 캐릭터는 생존)
  • 모든 캐릭터 소진 + 당일 생성권 없음 → 다음 날 대기
주의 — 일일 생성 한도(6개)가 보관함 슬롯 수(6칸)와 동일해짐. 하루치를 전부 생성하면 보관함이 가득 찬다. 노후 캐릭터 정리(링크 전환·방출) 동선을 함께 설계할 필요 있음 (부록 참조).

2-2랜덤 스탯

생성 시 힘 / 민첩 / 지능 / 행운 4종에 전부 랜덤 분배.

2-3특성 (Trait)

생성 시 Hidden(good/bad) / average / bad / Gamble 풀에서 랜덤 지정. 3차 전직(13레벨) 시 추가로 1회 더 추첨.

풀 선택 확률은 8-2 참조 (average 50% / bad 18% / Hidden-good 15% / Gamble 12% / Hidden-bad 5%). 풀이 정해지면 그 안에서 균등 추첨하므로, 각 풀 20종이면 풀 내 단일 특성 출현 확률은 1/20(5%)로 고르게 깔린다.

2-5전직 및 이능

전직은 총 4차. 각 전직 시 메이플 옛날 직업 스킬 3개 제시 → 1개 선택.

전직조건부가 효과
1차1레벨 (캐릭터 생성 시)—
2차5레벨 + 전직 퀘스트 보스 클리어—
3차13레벨 + 전직 퀘스트 보스 클리어랜덤 특성 1회 추가 지급
4차18레벨 + 전직 퀘스트 보스 클리어—
  • 전직 퀘스트 보스 클리어: 캐릭터 귀속 — 캐릭터마다 직접 처치
  • 보스 클리어 타임 기록: 계정 귀속 — 리더보드 반영
  • 이능은 3레벨 단위(3·6·9·12·15·18·21)로 총 7회 제공

이능 발동 시 아래 3종 중 랜덤 제시 → 1개 선택:

스탯 재분배보유 스탯 총량 유지한 채 4종에 재분배
추가 스탯 제공특정 스탯에 고정량 추가
특성 변경현재 특성을 새 랜덤 특성으로 교체

2-6링크 캐릭터 패시브

  • 링크 캐릭터는 15레벨 이상일 때 본인에게 배정된 링크스킬(2-8 참조)을 공격대에 제공
  • 15레벨 미만은 링크 효과 없음
  • 링크 슬롯 2칸 → 서로 다른 링크스킬 최대 2개 중첩 (동일 링크스킬은 중첩 불가)
  • 링크 마스터 특성 보유 시 링크 패시브 효율 +20% / 박애주의자 보유 시 3배 / 친화력 보유 시 소폭 증가
  • 외골수 특성 보유 시 링크 패시브 효율 절반 / 고독 특성 보유 시 링크 효과를 받지 못함
  • 링크로 쓰던 캐릭터도 언제든지 플레이어블로 전환 가능
  • 미배치 슬롯은 부캐 육성 또는 링크 풀 비축 용도로 자유 활용

FLOW링크 캐릭터 육성 흐름

새 캐릭터 생성 (링크스킬 1개 랜덤 배정) ↓ 플레이어블로 직접 플레이 → 15레벨 달성 ↓ 링크 슬롯에 배치 → 배정된 링크스킬 활성화
특성(정체성) · 패시브 스킬(본인 전투 기믹) · 링크스킬(아군 지원)은 서로 독립된 3개의 100종 풀이다. 특성이 좋아서 링크로 쓰는 게 아니라, 링크스킬 자체가 생성 시 별도로 랜덤 배정된다.
2-7

패시브 스킬

패시브 스킬은 특성과 무관하게 전직 시 획득하는 상시 발동 스킬이다. 각 전직(1·2·3·4차)에서 액티브 스킬 3택 1과 별개로 패시브 스킬도 3택 1을 제공 → 4차 전직까지 최대 패시브 4개 보유. 큐브마스터 특성/재추첨권으로 재추첨 가능.

성격: 본인이 조작하며 터뜨리는 전투 기믹 — 온-크리, 온-킬, 반격, 도트 등 트리거형 위주. 2-8과 함께 별도 100종 풀이며, 전체 목록은 부록 A에 수록.
2-8

링크스킬

링크스킬은 패시브 스킬과 무관한 별도 풀이다. 캐릭터 생성 시 1개가 랜덤 배정되며, 그 캐릭터를 15레벨 이상으로 키워 링크 슬롯에 넣으면 배정된 링크스킬이 공격대(플레이어블)에 활성화된다.

성격: 배경의 아군이 꾸준히 대주는 지원 — 오라·경제·안전망·상황 버프 등 상시형 위주. 동일 링크스킬은 링크 2슬롯에서 중첩되지 않는다. 전체 목록은 부록 B에 수록.
03

전투 시스템

3-1조작

  • 이동 — 방향키 / 가상 조이스틱
  • 기본 공격 — 자동 평타(근처 적 자동 타격) + 수동 보정
  • 스킬 — 쿨다운 기반 버튼 (전직으로 슬롯 확장, 최대 4개)

3-2데미지 산출 (개략)

최종 데미지 = (공격력 × 스킬 계수) × 크리티컬 배율 − 몬스터 방어력 · 공격력 : 힘(물리) / 지능(스킬)에서 산출 · 크리티컬 : 행운(LUK) 기반 확률·배율 · 공격 속도 : 민첩(DEX) 기반 → 초당 타격 횟수에 영향

3-3생존 자원

  • HP: 0이 되면 영구 사망 (부활자 특성 보유 시 1회 부활)
  • MP: 스킬 사용 자원 (지능이 최대치, 절약가 특성이 소모 감소)
  • 회복 아이템: 드랍으로 획득 (먹보 특성이 회복량 증가 / 버서크·금욕은 적용 불가)
04

스킬 시스템

각 전직마다 메이플스토리 5차 이전 직업 스킬 3개 제시 → 1개 선택. 스킬 풀은 차수별 분리, 풀 내에서는 전 직업 통합 → 하이브리드 빌드 가능.

시점스킬 풀슬롯 합계
1차 전직 (생성 시)전 직업 1차 스킬1개
2차 전직 (5레벨)전 직업 2차 스킬2개
3차 전직 (13레벨)전 직업 3차 스킬3개
4차 전직 (18레벨)전 직업 4차 스킬4개
큐브마스터 특성 보유 시 스킬 선택 제시 시 1회 재추첨 가능. 외길(Hidden-bad) 특성 보유 시 스킬 슬롯 최대 2개로 제한. 위 표는 액티브 스킬(조작 스킬) 기준 — 같은 전직 시점에 패시브 스킬도 3택 1로 별도 지급된다 (2-7 참조).

부록 C. 설계 메모 (패시브 · 링크)

  • 레이어 역할 분리 — 패시브는 온-크리/온-킬/반격/도트처럼 터뜨리는 기믹, 링크는 오라/경제/안전망처럼 대주는 지원. 같은 크리 계열이라도 패시브 "폭심(크리 시 폭발)" vs 링크 "조준 지원(크리뎀 +15% 상시)"로 성격이 다르다.
  • 획득 확정 필요(택1) — ① 패시브 스킬을 전직 3택으로 줄지, ② 이능과 번갈아 줄지, ③ 별도 패시브 슬롯을 둘지 — 현재 안은 ①(전직 3택). 링크스킬은 생성 시 랜덤 배정안. 원하는 방식으로 조정 가능.
  • 수치 검토 1순위(패시브) — 흡수(흡혈)·치명타 강화·불굴(치명타 무효)·처치 연쇄는 베이스라인에서 셀 수 있음.
  • 수치 검토 1순위(링크) — 후원(재화 +20%)·조준 지원(크리뎀 +15%)·최후의 인연(부활)·유대의 절정은 우선 조정 대상.
  • 중복/과적 방지 — 링크는 동일 링크스킬 미중첩(기존 규칙). 패시브도 완전 동일 효과 2개는 합연산 상한을 둘지 검토.
  • 레어도 연계(선택) — 특성처럼 패시브·링크에도 등급(common/rare/legendary)을 얹어 전직 3택·링크 배정 시 가중치를 줄 수 있음. 필요하면 100종 각각에 등급 태깅해 드림.
