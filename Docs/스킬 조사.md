# 스킬 조사 (2026-10-01)

> ⚠️ **전체 OBSOLETE (2026-10-03 기준)** — 이 문서가 조사한 "40종" 스킬 로스터는 2026-10-02 유저 제공 엑셀(메이플스토리 스킬목록 차수별) 반영으로 **전부 교체**됐다. 아래 §1의 이름·수치·분류, §2의 "실제 메이플스토리와 다르다"는 지적 전부 지금은 해당 스킬 자체가 존재하지 않거나(더블스윙/파워가드/썬더볼트 단일판/블리자드/애로우레인/허리케인/배틀쉽/아수라/이글아이/라이징슬래시/마크오브어쌔신/너클부스터 등) 이름·메커니즘이 바뀐 뒤라 **더 이상 유효하지 않다**. 현재 44종 로스터의 유일한 소스 오브 트루스는 `RootDesk/MyDesk/Skills/SkillCatalog.mlua`이며, 거기 담긴 변경 주석(특히 "2026-10-02 유저 엑셀 전체 반영" 태그가 붙은 항목들)이 이 문서가 지적한 구 시스템의 대체 기록이다. 이 문서는 당시 조사 과정의 역사적 기록으로만 남겨두고, 더 이상 참고하지 말 것.

리롤 용사(구 랜덤 플래닛)의 **전직 액티브 스킬 시스템**을 기획서 기준과 실제 구현 기준으로 전수 조사한 문서(작성 시점 기준 — 아래 내용은 모두 구버전). 요청 3가지에 각각 답한다.

1. 기획서 상 스킬 목록
2. 실제 리롤 용사에 적용된 스킬 목록 (전체 40종)
3. 실제 구현된 스킬들 중 어떤 것들이 "진짜 메이플스토리" 기준 효과와 다른지

## 0. 먼저 알아야 할 것 — 기획서에는 "스킬 목록" 자체가 없음

`Docs/랜덤 플래닛 전체 기획서.md` §04 "스킬 시스템"을 원문 그대로 인용한다:

> 각 전직마다 **버프 스킬 풀 3택1 + 액티브 공격 스킬 풀 3택1**을 각각 진행해 총 2개를 동시에 획득한다(메이플스토리 5차 이전 직업 스킬에서 발췌). (...) **액티브 스킬 자체는 커스텀 설계가 아니라 메이플스토리 기존 직업 스킬(5차 이전)을 그대로 가져와 쓰는 것이라 별도 100종 목록은 없음 — 다만 각 직업 스킬을 "버프형"/"공격형"으로 분류하는 태깅 작업이 별도로 필요하다(미착수).**

더 오래된 콘테스트 제출본(`Docs/회성시치의 게임만들기 프로젝트/random_hunters_full_document (1).md`)의 §4도 동일하게 "메이플스토리 5차 이전 직업 스킬 3개 제시 → 1개 선택"이라고만 쓰여 있고, 어느 쪽 문서에도 스킬 **이름**이 하나도 나열돼 있지 않다. (참고로 `부록 A. 패시브 스킬 100종` / `부록 B. 링크스킬 100종`은 이것과 **다른 시스템** — 특성에 내장된 패시브/링크 효과 목록이고, 지금 묻는 "전직 때 고르는 액티브 스킬"과는 무관하다.)

즉 **"기획서 상 스킬 목록"은 존재하지 않는다.** 기획서가 정한 것은 아래의 **구조 규칙**뿐이고, 실제 스킬 40종(이름·이펙트·수치)은 전부 구현 단계에서 "실제 메이플스토리 지식에 기반한 최선의 추정"으로 채워 넣은 것이다(`SkillCatalog.mlua` 자체 주석에 명시돼 있음 — 아래 §3 참고).

### 기획서가 실제로 정한 구조 규칙

| 시점 | 버프 스킬 풀 | 공격 스킬 풀 | 슬롯 합계 |
|---|---|---|---|
| 1차 전직 (캐릭터 생성 시) | 전 직업 1차 버프 3택1 | 전 직업 1차 공격 3택1 | 1+1 = 2개 |
| 2차 전직 (5레벨) | 전 직업 2차 버프 3택1 | 전 직업 2차 공격 3택1 | 2+2 = 4개 |
| 3차 전직 (13레벨) | 전 직업 3차 버프 3택1 | 전 직업 3차 공격 3택1 | 3+3 = 6개 |
| 4차 전직 (18레벨) | 전 직업 4차 버프 3택1 | 전 직업 4차 공격 3택1 | 4+4 = 8개 |

- **큐브마스터** 특성: 버프/공격 각각 1회 재추첨 가능.
- **외길**(Hidden-bad) 특성: 1차분만 유지, 이후 전직 스킬 획득 중단.
- 버프/공격 풀을 분리한 이유(2026-08-11 결정)도 기획서에 기록돼 있음: 버프(곱연산, 계속 누적)와 공격(합연산, 독립 가산)이 같은 풀에서 경쟁하면 "운 좋게 버프 먼저 뽑은 캐릭터"가 구조적으로 유리해지는 격차가 시간이 지나도 줄어들지 않는 문제가 있어, 매 전직마다 버프 1 + 공격 1을 반드시 함께 보장하도록 슬롯을 나눔.

## 2. 실제 메이플스토리 대비 효과가 다른 스킬 — 조사 결과

`SkillCatalog.mlua` 자체 주석에 이미 다음 사실이 기록돼 있다: **1차 스킬 10종은 2026-08-13~17 사이 4차례에 걸쳐 실제 메이플스토리 리소스/효과와 정밀 대조됐고(이펙트 리소스 팩을 프레임 단위로 직접 열어 확인), 2~4차 스킬 30종은 "메이플스토리 지식 기반 최선의 추정 — 전부를 백과사전 수준으로 검증하지는 못함"**이라고 스스로 명시돼 있다. 이번 조사는 그 미검증 30종을 웹 검색으로 실제 메이플스토리 위키/공략 자료와 대조해 보완한 것이다.

### 🔴 효과 자체가 실제 메이플스토리와 다른 것 (단순 수치 차이가 아니라 메커니즘 종류가 다름)

| 스킬 | 구현된 효과 | 실제 메이플스토리 효과 | 차이 |
|---|---|---|---|
| **파워 가드** (검사 2차 버프) | 받는 피해 15% 감소(순수 경감) | 몸빵 공격을 **40% 반사**(상대에게 40%, 나는 60%만) — 경감이 아니라 **반사** | 메커니즘 종류 자체가 다름 |
| **소울 애로우** (궁수 2차 버프) | 공격 속도 증가 | 화살 **소모가 없어짐**(인벤토리 화살 불필요) + 소폭 공격력. **공격 속도와 무관** | 완전히 다른 효과 |
| **썬더 볼트** (마법사 2차 공격) | 단일 대상 원거리 1회 타격 | 최대 **6마리를 3회씩** 타격하는 광역 다단히트 | 단일 대상 ↔ 광역 다단, 구조적으로 다름 |
| **매직 부스터** (마법사 3차 버프, 실제로는 "Spell Booster") | 스킬 피해 +25% | **스킬 딜레이(시전 속도) 감소** — 데미지와 무관 | 데미지 버프 ↔ 속도 버프 |
| **베놈** (도적 3차 공격) | 평타의 160% 단발 피해 | 독을 발라 **초당 % 피해를 수 초간 틱**(도트 데미지), 최대 3중첩 | 즉발 데미지 ↔ 도트(지속) 데미지 |
| **스피드 인핸서** (해적 3차 버프, 실제로는 "Speed Infusion") | 이동 속도 증가 | 해적 계열 "Speed"는 실제로 **공격 속도**를 뜻함(Max Knuckle Booster 선행 필요) | 이동속도 ↔ 공격속도 |
| **배틀쉽** (해적 4차 버프) | 자기 자신 공격력 +20% (순수 버프) | 커세어의 상징 스킬 — **함선을 소환**해 포격/어뢰를 독립적으로 발사하는 소환 메커니즘 | 자가 버프 ↔ 소환형 공격 |

| **레이지** (검사 4차 버프) | 자신만 공격력 +20%, 단점 없음 | 파이터의 실제 Rage는 **파티 전체**에 적용되고, 공격력을 올리는 대신 **방어력이 같은 수치만큼 감소**하는 트레이드오프 버프 | 파티→자신, 디버프 요소 누락 |
| **아이언 윌** (검사 3차 버프) | 자신만 피해감소 20% | 실제는 **스피어맨 전용**, 파티 전체 방어력 증가(아이언 바디와 중첩 불가) | 직업 계보 다름(워리어 일반이 아니라 스피어맨), 파티→자신 |
| **메디테이션** (마법사 2차 버프) | 자신만 스킬피해 +20% | 실제는 **파티 전체** 마력(Magic ATT) 증가 | 파티→자신 |
| **샤프 아이즈** (궁수 3차 버프) | 자신만 크리티컬 확률 +30% | 실제는 **파티 전체**, 크리 확률 **+크리 데미지** 둘 다 증가(4차 스킬) | 파티→자신, 크리뎀 요소 누락 |
| **헤이스트** (도적 2차 버프) | 이동속도만 증가 | 실제는 이동속도 **+ 점프력**, 파티 전체, 영구 소폭 증가분도 포함 | 점프력/파티 요소 누락 |
| **인피니티** (마법사 4차 버프) | 스킬피해 +40%만 | 실제는 스킬 MP 소모 없음 + 파워스탠스 확률 + HP/MP 자동회복 + 마법 공격력 증가가 **복합**된 효과(피격으로도 안 풀림) | 복합효과 중 "데미지 증가" 한 요소만 구현 |
| **쉐도우 파트너** (도적 3차 버프) | 공격 속도 증가로 "흉내" | 실제는 **분신을 소환**해 70% 위력으로 함께 공격하는 소환형 — desc 문구("분신이 함께 공격해... 동작합니다")가 이미 이 단순화를 자인하고 있음 | 코드 주석에도 의도적 재해석으로 기록돼 있어 숨겨진 버그는 아님 |
| **허리케인** (궁수 4차 공격) | 키 입력 1회당 5연타 | 실제는 **키를 누르고 있는 동안 계속** 발사(이동 가능, 이동속도 100으로 제한) | 홀드형 → 프레스형으로 단순화 |

### ⚪ 실제 메이플스토리에 해당 이름의 스킬이 존재하지 않거나 계보가 다름 (이름만 "메이플풍")

| 스킬 | 비고 |
|---|---|
| **메테오 스트라이크** (마법사 4차 공격) | 웹 검색으로 실제 메이플스토리 스킬 중 이 이름을 가진 것을 찾지 못함 — 다른 게임(마비노기/테라 등)에는 존재. 사실상 신규 창작명으로 추정 |
| **이글 아이** (궁수 4차 버프) | 실제로 존재하긴 하나 **윈드 아처(후속 전직 계열) 3차 스킬**이며 효과도 "영웅적인 모습으로 변신"으로 전혀 다름 — 클래식 익스플로러 궁수 계보가 아님 |
| **라이징 슬래시** (검사 3차 공격) | 실제로 존재하나 **하야토 또는 제로(베타)** 전용 — 클래식 검사 계보가 아님 |
| **아수라** (도적 4차 공격) | 실제 "아수라"는 **호영의 패시브 스킬**이고, "아수라의 분노"는 **블레이드마스터(5차, 160레벨)** 스킬 — 둘 다 클래식 도적/어쌔신 계보가 아니며, 액티브 공격기도 아님 |
| **애로우 레인** (궁수 3차 공격) | 실제로 존재하나 **윈드 아처 3차** 스킬(익스플로러 레인저 계보 아님) — 효과(최대 6마리 타격)는 비슷해 콘셉트상으로는 그나마 가까움 |

> 위 "⚪" 항목들은 전부 `SkillCatalog.mlua` 자체 주석이 "백과사전 수준 검증은 못 함"이라고 미리 고지해 둔 2~4차 스킬 묶음에 속한다 — 즉 이미 알려진 한계이지 이번에 처음 드러난 결함은 아니다.

### 🟢 이미 2026-09-29 QA에서 발견·수정 완료된 항목 (참고용, 재조사 불필요)

1차 전직 스킬 10종은 이미 다회 검증(위 §0 참고)됐고, 아래 3건은 지난 QA 세션(커밋 `5951c05`)에서 **설명 텍스트와 실제 판정이 안 맞던 것**을 찾아 이미 고쳤다 — 지금은 desc 쪽을 실제 동작에 맞게 정정해 둔 상태:

- **더블 스윙 / 더블 스탭** — desc에 "두 번"이라는 표현이 있었으나 실제론 `melee_single`(1회 타격)이라 삭제.
- **마크 오브 어쌔신** — desc가 "적에게 표식을 새겨"처럼 대상 지정 메커니즘이 있는 것처럼 읽혔으나, 실제는 `atkbonus`(자가 버프, 레이지/배틀쉽과 동일 패턴) — "표식의 기운을 두르고" 식 자가 버프 표현으로 수정.

### 🔵 이번 조사에서 새로 발견한 사소한 불일치 (설명 문구 간 수식어 불일치)

`PlayerBuffLogic.DoBuff`를 직접 열어보면 `atkspeed`(공격속도 증가) 계열 버프는 전부 `AttackCooldownSeconds * 0.4`로 **완전히 동일한 수치**(쿨다운 60% 감소)가 적용된다. 그런데 desc 문구의 강도 표현이 스킬마다 다르다:

| 스킬 | desc 표현 |
|---|---|
| 너클 부스터 | "크게 증가" |
| 쉐도우 파트너 | "크게 증가" |
| 소울 애로우 | "증가"(크게 없음) |
| 리로드 | "증가"(크게 없음) |

실제 수치는 넷 다 동일한데 "크게"가 붙었다 안 붙었다 하는 건 플레이어에게 미묘하게 잘못된 체감 기대치를 줄 수 있다. 치명적이진 않지만 일괄 정리하면 좋을 항목.

## 3. 요약

- **기획서에는 스킬 "목록"이 없다.** 기획서는 전직 차수별 슬롯 구조(버프/공격 3택1씩)만 규정했고, 실제 스킬 40종의 이름·수치·이펙트는 전부 구현 단계에서 "진짜 메이플스토리에서 가져온다"는 원칙 아래 채워졌다.
- **1차 스킬 10종**은 이미 여러 차례 실제 리소스·효과 대조를 거쳐 신뢰도가 높다(의도적 타협 2건은 코드에 명시: 럭키세븐/너클부스터는 원래 2차 스킬).
- **2~4차 스킬 30종**은 "최선의 추정"으로 시작해 한 번도 전수 검증되지 않았었다. 이번 조사로 **7건의 메커니즘 수준 불일치**(파워가드/소울애로우/썬더볼트/매직부스터/베놈/스피드인핸서/배틀쉽), **7건의 범위·부가효과 단순화**(파티→자신 위주), **5건의 이름/계보 자체가 실제 메이플과 다른 스킬**을 확인했다.
- 전부 "실제로 재밌게 작동하느냐"보다 "실제 메이플스토리 지식과 얼마나 일치하느냐"를 기준으로 한 조사라는 점에 유의 — 밸런스나 재미 자체에 문제가 있다는 뜻은 아니다. 수정 여부/우선순위는 별도 판단 필요.
