## 1. One-line concept
> 전체 기획서(§0~09 + 부록 A~H)의 프로덕션 스펙을 인게임에 전면 편입 — 114종 특성(기본+링크 패시브 내장) · 4차 전직 하이브리드 스킬 · 링크 캐릭터 · 몬스터 게이트 · 난이도 4단계 · 계정 메타강화 · 리더보드까지 갖춘 "완전판" 로그라이트로 확장한다.

## 2. Key decisions (M1에서 유지)
전체 기획서와 인게임 GDD가 이미 갈라진 지점은 **인게임 쪽을 기준으로 유지**한다 (되돌리지 않음):
- 조작: 완전 수동 (자동전투 없음) — 전체 기획서 §3-1의 "자동 평타" 문구는 무시

- 맵: MapleTile 사이드뷰 유지
- 세션 길이 1시간 목표는 §8-3 EXP 재조정 시점에 반영 (Phase I)

## 3. M2 로드맵 (Phase A~J)

- ⬜ 커밋 안 된 5개 파일 diff 검토 후 커밋 (Maker 자동 정규화인지 실질 변경인지 확인)
- ⬜ 스킬 티어 3택1 선택 팝업 (버프풀 카드 3장 + 공격풀 카드 3장, 큐브마스터 재추첨 버튼 포함 — 전체 기획서 §07 "스킬 선택 팝업") — `GrantTierSkills`를 자동지급에서 실제 선택 흐름으로 교체
- ⬜ 2번 스킬 슬롯 `.ui` 바인딩 + HUD 표시 + 키 설정 팝업 아이콘
- ⬜ VFX 타이밍 딜레이 적용 (설계 완료분 코드화)
- ⬜ 물약 시스템 (드랍 → 인벤토리 소비 탭 → 사용 → HP 회복, 버서크/금욕 특성 적용 불가 규칙 연결)
- ⬜ 던전(토벌전장 1~3) 클리어 가능성 시뮬레이션/실측 검증
- ⬜ M1 마일스톤 공식 완료 처리 (GDD `Archive/`로 이동, `Archive/As-built.md` 최종화)

### Phase B — 특성 시스템 전면 확장 (114종, 최우선 — 게임 정체성의 핵심)
> 전체 기획서 §2-3(114종 5풀) + §8-2(풀 확률+천장) + 부록 D(링크 패시브 115쌍) + 부록 E(기본 패시브 100쌍) + 부록 G(신규 15종 자체 효과) 전면 반영.
- ⬜ **데이터 구조 설계**: 114(115)종 특성을 `UserDataSet`(CSV)로 이관 — 풀 구분(Hidden-good/Hidden-bad/average/bad/Gamble), 기본 패시브 효과, 링크 패시브 효과, 수치 파라미터
- ⬜ **범용 효과 적용 엔진**: 114종 각각을 bespoke 스크립트로 만들지 않고, 공통 효과 타입(스탯 배율, 온크리/온킬 트리거, 도트, 흡혈, 드랍률, 쿨다운, 특수 규칙 등)을 파라미터화한 `TraitEffectEngine` 설계 — 부록 G의 시그니처 메커니즘(진화의 손길·환영 교체·시간을 거스르는 자 등)만 개별 스크립트로 예외 처리
- ⬜ 5풀 확률 가중치(35/20/20/18/7%) + 소프트/하드 천장(Pity) 구현 (§8-2)
- ⬜ 캐릭터 생성 시 특성 배정 로직을 축소 풀(6종)에서 전체 풀로 교체
- ⬜ 3차 전직(13레벨) 추가 특성 1회 재추첨 연결
- ⬜ 기본 패시브 114종 전체 구현 (부록 E 매핑)
- ⬜ 링크 패시브 114종 전체 구현 (부록 D 매핑) — Phase C에서 실제 스쿼드 적용과 함께 마무리
- ⬜ 실측 밸런스 검증 (버서크 재설계 때처럼 결정론적 시뮬레이션으로 최소 상위 20~30종 검증)

### Phase C — 링크 캐릭터 실효과 연결
- ⬜ 15레벨 이상 링크 캐릭터의 링크 패시브를 실제로 스쿼드에 적용 (동일 링크 패시브 중복 불가 규칙)
- ⬜ 링크 마스터(+20%)/박애주의자(3배)/친화력(소폭)/외골수(절반)/고독(차단) 특성의 효율 보정 연결
- ⬜ 공격대 편성 UI에 링크 패시브 미리보기 추가

### Phase D — 전직 시스템 완성 (4차, 메이플 옛날 직업 스킬 하이브리드)
- ⬜ 기존 `SkillCatalog.mlua`(10종, 1차 한정)를 4차 전직 전체로 확장 — 각 전직마다 버프 3택1 + 공격 3택1 (전체 기획서 §04 표)
- ⬜ 전직 퀘스트 보스 연결 (5·13·18레벨, 클리어해야 다음 차수 스킬 획득)
- ⬜ 보스 클리어 타임 계정 귀속 기록 (리더보드 연동, Phase H)
- ⬜ 봉인된 자(1차 한정)/외길(2슬롯 한정)/봉인구(4차 불가) 등 특성-전직 상호작용 규칙 연결

### Phase E — 몬스터 게이트 (특수 던전)
- ⬜ 게이트 입장권 재화 + 인벤토리 연결 (전장/보스 드랍으로 획득)
- ⬜ 좌우 조여오는 몬스터 웨이브 패턴 (기존 `FieldWaveSpawner` 확장 또는 신규 `GateWaveSpawner`)
- ⬜ 스탯 3배/물량 2배 스케일링
- ⬜ 게이트 보스 등장 + 클리어 보상 (이능 재선택권, 고급 스탯 구슬)

### Phase F — 난이도 4단계 스케일
